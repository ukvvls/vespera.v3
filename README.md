# VESPERA V3 — Player System

واجهة عربية RTL بنمط Liquid Glass، مع انتقالات خفيفة بين الصفحات.

## الملفات
- `index.html` — الموقع الرئيسي.
- `admin.html` — تصدير واستيراد نسخة بيانات محلية للمتصفح الحالي.
- `config.example.js` — نموذج إعداد عنوان Worker.
- `worker.js` — واجهة Cloudflare Workers AI (اختيارية) مع طلب تأكيد قبل إضافة أو إكمال مهمة مقترحة من AI.
- `wrangler.jsonc` — إعداد ربط Workers AI.

## النشر على GitHub Pages
1. ارفع `index.html` و`admin.html` إلى جذر المستودع.
2. اترك `config.example.js` و`worker.js` و`wrangler.jsonc` ضمن ملفات المشروع.
3. من Settings → Pages اختر Deploy from a branch ثم `main` والمجلد `/ (root)`.
4. افتح رابط Pages وانتظر اكتمال النشر.

الموقع يعمل دون تسجيل دخول، ويحفظ بيانات اللاعب في `localStorage` على الجهاز الحالي. البيانات لا تتزامن تلقائيًا بين الأجهزة.

## إعداد المساعد السحابي (اختياري)
- لا تضع مفاتيح API في ملفات الواجهة أو GitHub.
- انشر `worker.js` كـ Cloudflare Worker مع Workers AI binding باسم `AI` باستخدام `wrangler.jsonc`.
- تحقق من شروط الخدمة والأهلية العمرية للمنصة، واستعن بولي أمر إذا كان ذلك مطلوبًا.
- بعد النشر، انسخ `config.example.js` إلى `config.js` وضع رابط Worker في `AI_WORKER_URL`.
- ارفع `config.js` فقط إذا كان يحتوي على رابط Worker عام لا أسرارًا أو مفاتيح.
- عنوان Worker عام، وCORS ليس بديلًا عن حماية الاستخدام أو تحديد المعدل. راجع إعدادات الحماية والحدود قبل إتاحة المساعد للجمهور.

النموذج المحدد حاليًا: `@cf/google/gemma-4-26b-a4b-it`. يمكن تغييره إلى نموذج مدعوم في حسابك عند النشر.

## ملاحظات
- قسم FITNESS اختياري ومنفصل عن المهام اليومية، ولا يضيف مهام تلقائيًا.
- BMI رقم معلوماتي فقط وليس تشخيصًا؛ للمستخدمين دون 18 عامًا يلزم تفسيره وفق العمر والنمو بواسطة مختص.
- لا يوجد حساب تلقائي لسعرات التنشيف أو عجز السعرات أو أهداف الوزن.
- المساعد المحلي يدعم أوامر أساسية حتى قبل ربط Worker.
